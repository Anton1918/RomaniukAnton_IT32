1. У таблиці `trips` додано `duration_hours` — тривалість рейсу в годинах: `duration_min / 60.0`.
2. У таблиці `drivers_routes` додано `is_active`: значення `1` для статусу «активний», `0` для іншого статусу, `NULL` для порожнього значення. У наявних 8 записах статус активний, тому прапорець дорівнює `1`.
3. Спроба змінити `duration_hours` напряму дала помилку SQLite: **`cannot UPDATE generated column "duration_hours"`**.
4. Для рейсу з `id = 1` змінено `duration_min` зі 150 на 180. Значення `duration_hours` автоматично змінилося з 2,5 на 3,0.
5. Запит `WHERE duration_hours > 2` відібрав 7 рейсів.

# Контрольні запитання

1. Тому що стовпці додаються до вже створених таблиць через `ALTER TABLE`. SQLite дозволяє так додати `VIRTUAL`, але не `STORED`. Значення `VIRTUAL` обчислюється під час читання.

2. Згенерована колонка залежить від базової. SQLite не дозволить видалити колонку, якщо через це зламається вираз згенерованої колонки.

3. Це не дозволяє вручну записати неправильне похідне значення. SQLite сам обчислює його за формулою, тому дані залишаються узгодженими.
