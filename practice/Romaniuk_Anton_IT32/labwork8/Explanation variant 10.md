# Завдання 1
У таблиці `trips` усі поля мають `NOT NULL`, тому записати `NULL` через `UPDATE` неможливо — SQLite повертає помилку `NOT NULL constraint failed`. Для наявних даних `COUNT(*)` і `COUNT(duration_min)` дають однаковий результат: **10**.

Окремо показано, що `COUNT(колонка)` не рахує `NULL`: у тестовому наборі з одним значенням і одним `NULL` результат становить **1**.

# Завдання 2
Для `duration_min`:
- `SUM = 1690` хв.
- `AVG = 169` хв.

`SUM` обчислює загальну тривалість, а `AVG` — середню тривалість однієї поїздки.

# Завдання 3
Для `trip_date`:
- `MIN = 2026-09-01` — перша дата поїздки.
- `MAX = 2026-09-12` — остання дата поїздки.

# Завдання 4
Одним запитом отримано:
- кількість поїздок — **10**;
- загальна тривалість — **1690 хв**;
- середня тривалість — **169 хв**;
- мінімальна — **75 хв**;
- максимальна — **315 хв**.

# Завдання 5
Для поїздок із `duration_min > 200`:
- кількість — **3**;
- сума — **855 хв**;
- середня тривалість — **285 хв**.

`WHERE` спочатку відбирає потрібні рядки, після чого агрегатні функції працюють лише з ними.

# Контрольні питання

1. `COUNT(*)` рахує всі рядки, а `COUNT(колонка)` — лише рядки, де ця колонка не `NULL`.
2. Для 5 значень, з яких одне `NULL`, `AVG` використовує 4 числові значення, тому ділить суму на **4**, а не на 5.
3. `SUM(колонка)` для набору, де всі значення `NULL`, повертає `NULL`, а не 0.
4. `WHERE` фільтрує рядки до виконання агрегатної функції.
