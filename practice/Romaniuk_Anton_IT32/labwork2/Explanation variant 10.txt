Завдання 1.
Використано явний перелік потрібних стовпців замість SELECT *. Це дозволяє отримати лише потрібні дані.

Завдання 2.
Для варіанта 10 обрано умову experience_years > 5 — вибір водіїв зі стажем понад 5 років.

Завдання 3.
LIMIT 3 виводить лише перші три записи таблиці.

Завдання 4.
Для перевірки NULL обрано experience_years, оскільки стаж водія може бути невідомим. Додано запис зі значенням NULL.
IS NULL знаходить записи з невідомим значенням, а IS NOT NULL — записи, де значення відоме.
Запит WHERE experience_years = NULL використовувати не можна, тому що NULL не є звичайним значенням для порівняння через =.

Завдання 5.
Використано складену умову через AND: experience_years > 5 AND license_category LIKE '%C%'. Вона вибирає водіїв, які одночасно мають понад 5 років стажу та категорію C.


Контрольні питання

1. NULL означає відсутність або невідомість значення, тому його не можна перевіряти звичайним оператором =. Запит WHERE price = NULL не дасть потрібного результату. Для перевірки потрібно використовувати IS NULL.
2. WHERE фільтрує окремі рядки таблиці до виконання групування. HAVING використовується для фільтрації вже сформованих груп, зазвичай разом із GROUP BY. Наприклад, WHERE можна використати для вибору водіїв зі стажем понад 5 років, а HAVING — для відбору груп після підрахунку кількості водіїв.
3. SELECT * варто уникати, коли потрібні лише конкретні стовпці таблиці. Краще явно вказувати потрібні стовпці, наприклад SELECT last_name, first_name, оскільки це робить запит зрозумілішим, повертає тільки необхідні дані та не залежить від появи нових стовпців у таблиці.
